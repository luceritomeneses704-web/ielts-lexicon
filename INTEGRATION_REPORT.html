IELTS Lexicon · 雅思极简词典与生词本  ·  2026-10-17  ·  OALD 真实词库

一、交付概述

已将 DICT.zip（牛津高阶英汉双解词典 OALD 风格语料，GB18030 编码、174 个文件、约 4 万词条）完整整合进 App，项目位于 D:\ielts-lexicon。整合遵循你选择的「TS 词库并入前端」路线：解析生成的紧凑词库作为最低优先级兜底层进入现有 masterDictionaryMap 查词体系，不覆盖既有精选词库，不改变三视图结构与生词本数据格式。

38,954词库条目（含 781 个别名）
38,173独立词头
5,025词头带派生词关联
2,729存根词条已关联基础词

二、整合架构

DICT.zip（GB18030 文本）→ parse_oxford_dict.py（词条切分 / 音标清洗 / 中英切分 / 繁简转换 / 派生词计算）→ oxfordLexicon.ts（19.7MB 管道分隔紧凑数据）→ dictionaryService 最低优先级种子化 → masterDictionaryMap
→ 查词 Tier 1 命中（findLocalWord）· suggest 前缀匹配（getInstantSuggestions）· 生词本/闪卡自动打通（既有 recordWordLookup 链路）
  • 精选词库永远优先：剑桥雅思真题库、AWL、OFFLINE_LEXICON 等已覆盖的词不被牛津数据覆盖
  • 浏览器组件零影响：getAllMasterWords() 过滤牛津来源，「雅思核心词库速览」与「主词库」两个浏览器行为与性能不变
  • suggest 性能优化：改为直接迭代 Map，避免每次输入全量拷贝 4.2 万条目

六、启动方式

注意事项：① 采用 TS 词库路线后主 JS chunk 为 21.5MB（gzip 约 7.9MB），本地工具可正常使用；若未来要部署到线上并瘦身，可将词库改为 SQLite 后端方案（已评估过的备选路线）。② 音标保留牛津原记法（如 5beIbI; \`bebI），未做 IPA 转换以避免转换误差。③ 少量纯参见条目（约 700 条）无独立音标/释义，以「参见基础词」形式呈现。
